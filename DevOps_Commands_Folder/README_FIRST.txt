HOW TO USE
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open the relevant .txt file.
4. Copy commands one at a time into the VS Code PowerShell terminal.
5. Replace placeholder names/URLs where indicated.

NOTE
Some tasks require Docker Desktop, Node.js/npm, Git, kubectl and Minikube to be installed.
Do not run every command in a file blindly; some commands create or delete resources.
